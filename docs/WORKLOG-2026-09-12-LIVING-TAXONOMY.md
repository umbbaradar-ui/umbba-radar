## 4. 시기 필터 불일치 (임신중 21건 → 107건)

원인: 홈 허브 칩(`stageCounts`)은 **그 시기 태그가 붙은 카드만** 세는데, `/explore?stage=` 는 "그 시기 **또는 전연령**"으로
걸렀다. 리빙이 전부 전연령이라 86건이 모든 시기 필터에 얹혔다.
수정: `ExploreView.applyFilters` · `discovery/service.ts filterPosts` 의 특정 시기 필터를 **정확 매칭**으로. 전연령은 "전연령" 칩·
리빙 탭에서 따로 본다. 이제 허브 칩 건수 = 탐색 결과 건수.

같이 점검한 카운트↔목록 쌍 (일치 확인): 브리핑 "오늘 마감 N건" ↔ 마감 레이더 더보기(같은 모집단, 09-11 수정) · 키워드 칩 N ↔ 레일 ·
리빙 선반 "전체 보기 N건" ↔ `/explore?topic=living` · 필터 시트 "N건 보기" ↔ 결과.
"내 아이"(explore `my_child`)와 브리핑 "우리 아이 맞춤 N건"은 **내 시기 OR 전연령** 그대로 두되(둘이 서로 일치, 마감 레이더도 같은 모집단),
탐색 화면에서는 **2섹션으로 갈랐다**(은재 결정): 위 `💛 우리 아이 시기 맞춤 N건`(내 시기 정확 매칭) → 아래
`👨‍👩‍👧 전연령 신청 가능 상품도 확인하세요 N건`(리빙·가족 단위). 총 건수·정렬·신청함 맨뒤 규칙은 그대로, 순서만 보존한 채 둘로.
`ExploreView.myChildSplit` + `SectionDivider`(col-span-full). `card_open` meta 에 `section`(mine/all_ages) 추가.
검수용 dev 전용 `/explore?stage=my_child&preview=parent` (로그인+영아·유아 자녀 강제, 프로덕션 무시 — /test 의 view 스위처와 같은 취지).
