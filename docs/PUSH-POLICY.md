# 엄빠레이더 푸시 알림 정책 (v1)

> 확정 2026-06-22. 발송 인프라(cron)는 아직 미구현 — VAPID 점화 후 **이 문서를 기준으로** 구현.
> 대원칙: **개별 카드 = 알림 X. 하루치 몰아서 다이제스트. 조용한 시간 보호(육아앱).**

---

## 1. 발송 스케줄 — "둘 다" (아침=발견 / 저녁=행동)

| 시각 (KST) | 종류 | 내용 예시 |
|---|---|---|
| **아침 10:00** | 맞춤/신규 다이제스트 | "○○님, 안 본 사이 **내 아이 맞춤 N건**이 새로 떴어요 👶" |
| **저녁 20:00** | 마감 임박 | "⏰ 관심·신청한 카드 **N건**이 내일 마감돼요" |

- 아침 = 발견(맞춤·새 협찬), 저녁 = 행동 유도(마감).
- 각 시각 **0건이면 발송 안 함**.

---

## 2. 아침 다이제스트 계산

- **N = 마지막 발송(또는 마지막 방문) 이후**, 사용자가 켠 항목(맞춤·새 협찬)에 맞는 **신규 카드 수**.
- 자녀 등록자 → "내 아이 맞춤 N건". 미등록 → "새 혜택 N건" (**신규 ≥3건일 때만**).
- 클릭 → 홈(내 아이 필터).

## 3. 저녁 마감 임박

- 사용자가 **관심/신청함** 표시한 카드 중 **D-1(내일 마감)** 인 것.
- 클릭 → `/my`(내 레이더) 또는 해당 카드.
- 0건이면 발송 안 함.

---

## 4. 가드레일 (스팸·이탈 방지 — 정책 핵심)

| 룰 | 값 | 이유 |
|---|---|---|
| 시각당 최대 | **1건** (하루 최대 2) | 폭탄 금지 |
| **조용한 시간** | **21:00~08:00 발송 절대 금지** | 🔴 밤 알림 = 애 깨움 = 앱 삭제 |
| 0건 발송 | 금지 (N≥1) | 빈 알림 금지 |
| 오늘 방문함 | 아침 다이제스트 스킵 | 이미 봤는데 또 보내면 스팸 |
| 중복 | 이미 알린 카드 제외 | 같은 거 두 번 X |
| 미등록 사용자 신규 | ≥3건일 때만 아침 발송 | 1건 갖고 안 깨움 |

---

## 5. 재방문 / 이탈 단계

- **3일+ 미방문**: 문구 강조 — "3일 동안 못 본 맞춤 **N건**이 기다려요".
- **14일+ 미방문**: 발송 빈도 **주 1회**로 낮춤 (떠난 사람 안 괴롭힘).

---

## 6. 항목 선호 (사용자 설정 반영)

- 사용자가 끈 항목은 발송 제외. 항목: 전체 / 마감 임박 / 새 협찬·체험단 / 내 아이 맞춤 / 후기·꿀팁.
- 현재 저장 = `localStorage` 키 `umbba-radar:push-categories` (`PushSettings.tsx`).
- ⚠️ 발송 cron 도입 시 **서버 테이블로 동기화 필요** (cron이 클라 localStorage를 못 읽음).
