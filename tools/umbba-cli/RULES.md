# 엄빠레이더 카드 분류 룰 (Claude Code 용)

이 문서는 너님(사용자)이 운영하면서 매일 다듬는 살아있는 룰셋이에요. Claude Code 는 이 룰을 따라 `todo-YYYYMMDD.json` 의 각 게시물을 분류합니다.

---

## 입력 / 출력 형식

**입력**: `/api/admin/queue/export-todo` 가 만든 JSON
```json
{
  "exported_at": "2026-05-28T12:00:00Z",
  "count": 50,
  "items": [
    {
      "queue_id": "uuid…",
      "url": "https://www.instagram.com/p/…/",
      "source_username": "bebero.kr",
      "source_post_date": "2026-05-27T08:28:55Z",
      "caption": "BEBBERO 후르츠 딸기 세미오버핏…"
    },
    ...
  ]
}
```

**출력**: `results.json` — Import endpoint 가 받는 형식
```json
{
  "items": [
    {
      "queue_id": "uuid…",          // 입력 그대로 (매칭용)
      "skip": false,                  // true 면 카드 생성 X
      "title": "베베로 후르츠 딸기 옷 증정 이벤트",
      "brand_name": "베베로",
      "body": "댓글 + 친구 태그 → 30명 추첨…",
      "search_keywords": "베이비옷,오버핏",
      "stage_categories": ["newborn", "infant"],
      "type_tags": ["experience", "form"],
      "topic": "parenting",
      "deadline": "2026-06-05T23:59:00+09:00",
      "confidence": 0.92
    }
  ]
}
```

---

## 노이즈 = `skip: true` 처리

다음은 카드 생성 X:
- 단순 제품 자랑·일상 글 (모집·이벤트 키워드 없음)
- 협찬 후기만 (신청 방법 X)
- 매장 영업 시간 / 휴무 안내
- 다른 브랜드와 무관한 광고
- 정치·종교·논란성

이유는 `skip_reason` 에 한 줄 (예: "단순 후기, 모집 아님").

---

## 제목 작성 규칙 (한글 우선)

- **캡션에 명시된 핵심 제품·이벤트명을 그대로**
  - 좋은 예: "예비맘의 첫 병" → 캡션에 "신생아 젖병 2종 증정" 명시 → "신생아 젖병 2종 증정"
  - 나쁜 예: 이미지 헤드라인만 보고 "콜라보 제품 증정" (제품 누락)
- 끝맺음: "신청", "모집", "증정", "체험단 모집", "후기 모집"
- 마케팅 수사 ("최고", "절대 놓치지 마세요") 제거
- 이모지·해시태그·마침표·물음표·느낌표 금지
- 50자 이내

---

## 브랜드명 한글 우선

- "BEBERO" → "베베로", "Kakao" → "카카오", "Pampers" → "팸퍼스"
- 예외 (알파벳 약자 보편): LG, SK, GS, CJ, CU, NH, KB
- 한글 옆 영문 병기 X (예: "베베로 (BEBERO)" 금지)
- 캡션·이미지 어디에도 단서 없으면 `null`

### 자주 등장하는 브랜드 (운영하며 추가)

| 영문/원문 | 한글 표기 |
|---|---|
| BEBERO | 베베로 |
| Pampers | 팸퍼스 |
| Hegen | 헤겐 |
| Avauma | 아바마 |
| Petit halo | 쁘띠알로 |
| (추가) | |

## stage_categories (시기 분류)

- `pregnancy`: 임신중 — 산모·임산부·예비맘·태교·산후조리원
- `newborn`: 신생아 0~3개월 — 신생아·산후·조리원·배냇·모빌·젖병(첫 단계)·분유(1단계)
- `infant`: 영아 4~12개월 — 이유식·기저귀·옹알이·뒤집기·앉기·치발기·범퍼침대
- `toddler`: 유아 1~7세 — 유치원·어린이집·식판·키즈카페·교구·동화책·배변훈련
- `elementary`: 초등생 8~13세 — 초등학교·학용품·방과후
- `all_ages`: 전연령 — 식기·청소기·가전·식품·살림 (시기 무관 가족 단위)

### 룰
- **이유식·젖꼭지·치발기·기저귀 키워드는 절대 all_ages 단독 X** → 해당 시기 명시
- 캡션에 "0~3개월", "백일 아기", "신생아용" 직접 표현 있으면 그대로
- 어른·가족 단위(공기청정기, 식기세트)일 때만 all_ages

---

## type_tags (복수 가능)

- `regram`: 본인 피드에 리그램(재게시) 필수
- `experience`: 체험단 — 제품 받고 후기·SNS 게시 의무
- `kids_model`: 키즈모델·아동 모델
- `supporters`: 서포터즈 — 장기 SNS 활동 (주 N회) 약속
- `form`: 별도 폼 작성 필수 (구글폼·네이버폼·카카오톡 채널 신청서)
  - 댓글·DM 만으로 신청 가능하면 form 아님
  - 다른 태그와 자유 조합 가능 (예: experience + form)

---

## topic (필수, 둘 중 하나)

- `parenting`: 아이가 주체 (이유식·기저귀·완구·교구·키즈모델·아동 체험단)
- `living`: 살림 (가전·가구·식기·청소·침구 — 가족 단위)
- 애매하면 `parenting` (육아 사이트 디폴트)

---

## deadline 추출 (캡션 본문 적극 탐색)

자주 나오는 패턴:
- "~까지", "마감: X월 Y일", "X월 Y일(요일) 자정", "X/Y 23:59"
- "선착순 N명 (~ 마감)"
- "이번 주 일요일까지" → 게시일 기준 가장 가까운 일요일 23:59 KST
- "오늘부터 7일간", "1주일간" → 게시일 + 해당 기간

ISO 8601 with +09:00 형식. 없으면 `null` (시스템이 자동으로 게시일 + 7일로 처리).

---

## search_keywords (검색 동의어, 콤마 구분 1~3개)

사용자가 다른 표현으로 검색해도 잡히게 하는 보조 키워드. 제목·본문에 이미 있는 단어는 중복 X.

예시:
- "팬티 체험단" → "기저귀,기저귀팬티"
- "분유 샘플" → "이유식,수유용품"
- "조리원" → "산후조리원,산후도우미"
- "유모차" → "스트롤러,유모차세트"

동의어 안 떠오르면 `null`.

---

## confidence (0.0 ~ 1.0)

너님(Claude Code)이 분류에 얼마나 자신 있는지. 사용자 검수 우선순위 결정용.

- 0.9~1.0: 캡션·시각 단서 충분, 거의 확실
- 0.7~0.9: 일반적 케이스
- 0.5~0.7: 단서 부족, 검수 권장
- 0.5 미만: **너님이 사용자에게 한 번 확인 받고 결정** (Claude Code 가 대화로 물어봐 줘요)

---

## 사용자 (너님 = 운영자) 확인 요청 패턴

신뢰도 0.5 미만일 때, Claude Code 가 사용자에게 이렇게 물어봐주세요:
> "@bebero.kr · 5/27 게시
> 캡션: 'BEBBERO 후르츠 딸기 세미오버핏…'
> 모집 공고로 보기 애매한데, 카드로 등록할까요? (y / n / skip 사유)"

사용자가 답하면 그대로 반영.

## 검증

results.json 만든 후:
1. items 수 = 입력 items 수 ?
2. queue_id 다 매칭됐나 ?
3. skip 외 모든 항목이 title 있나 ?
4. stage_categories 가 배열 (string 아님) ?
5. deadline 이 ISO 8601 +09:00 형식 ?

이상 OK 면 사용자에게 결과 요약 보고 후 import 진행 안내.
