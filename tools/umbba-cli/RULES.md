# 엄빠레이더 카드 분류 룰 (Claude Code 용)

이 문서는 너님(사용자)이 운영하면서 매일 다듬는 살아있는 룰셋이에요. Claude Code 는 이 룰을 따라 `todo-YYYYMMDD.json` 의 각 게시물을 분류합니다.

---

## 입력 / 출력 형식

**입력**: `/api/admin/queue/export-todo` 가 만든 JSON
```json
{
  "exported_at": "2026-05-28T12:00:00Z",
  "count": 50,
  "items": [
    {
      "queue_id": "uuid…",
      "url": "https://www.instagram.com/p/…/",
      "source_username": "bebero.kr",
      "source_post_date": "2026-05-27T08:28:55Z",
      "caption": "BEBBERO 후르츠 딸기 세미오버핏…"
    },
    ...
  ]
}
```

**출력**: `results.json` — Import endpoint 가 받는 형식
```json
{
  "items": [
    {
      "queue_id": "uuid…",          // 입력 그대로 (매칭용)
      "skip": false,                  // true 면 카드 생성 X
      "title": "베베로 후르츠 딸기 옷 증정 이벤트",
      "brand_name": "베베로",
      "body": "댓글 + 친구 태그 → 30명 추첨…",
      "search_keywords": "베이비옷,오버핏",
      "stage_categories": ["newborn", "infant"],
      "type_tags": ["experience", "form"],
      "topic": "parenting",
      "deadline": "2026-06-05T23:59:00+09:00",
      "confidence": 0.92
    }
  ]
}
```

---

## 노이즈 = `skip: true` 처리

다음은 카드 생성 X:
- 단순 제품 자랑·일상 글 (모집·이벤트 키워드 없음)
- 협찬 후기만 (신청 방법 X)
- 매장 영업 시간 / 휴무 안내
- 다른 브랜드와 무관한 광고
- 정치·종교·논란성

이유는 `skip_reason` 에 한 줄 (예: "단순 후기, 모집 아님").

## 제목 작성 규칙 (한글 우선)

### ⚠️ 중요: 제목에 브랜드명 절대 X
**`brand_name` 은 카드 UI 에 별도 분홍 글씨로 표시**됩니다. title 에 넣으면 중복.
- ❌ 나쁜 예: "베베로 신생아 젖병 2종 증정" (브랜드 중복)
- ✅ 좋은 예: "신생아 젖병 2종 증정" (제품·이벤트명만)

### 형식: "(제품/대상) (이벤트 형식)"
- 캡션에 명시된 **핵심 제품 + 이벤트 종류** 조합
  - "신생아 젖병 2종 증정"
  - "허그곰 쿨링 베개 체험단 모집"
  - "베이비수트 모델 모집"
  - "100일 기념 빨대컵 증정"
  - "쿨링 선스프레이 체험단 모집"

### 끝맺음 (필수)
"신청" / "모집" / "증정" / "체험단 모집" / "서포터즈 모집" / "후기 모집" 중 하나로 종결.

### 금지
- 이모지·해시태그
- 마침표·물음표·느낌표
- 마케팅 수사 ("최고", "절대 놓치지 마세요", "지금 만나보세요")
- 50자 초과

## 브랜드명 한글 우선

- "BEBERO" → "베베로", "Kakao" → "카카오", "Pampers" → "팸퍼스"

- 한글 옆 영문 병기 X (예: "베베로 (BEBERO)" 금지)
- 캡션·이미지 어디에도 단서 없으면 `null`

## stage_categories (시기 분류)

- `pregnancy`: 임신중 — 산모·임산부·예비맘·태교·산후조리원
- `newborn`: 신생아 0~3개월 — 신생아·산후·조리원·배냇·모빌·젖병(첫 단계)·분유(1단계)
- `infant`: 영아 4~12개월 — 이유식·기저귀·옹알이·뒤집기·앉기·치발기·범퍼침대
- `toddler`: 유아 1~7세 — 유치원·어린이집·식판·키즈카페·교구·동화책·배변훈련
- `elementary`: 초등생 8~13세 — 초등학교·학용품·방과후
- `all_ages`: 전연령 — 식기·청소기·가전·식품·살림 (시기 무관 가족 단위)

### 룰
- **이유식·젖꼭지·치발기·기저귀 키워드는 절대 all_ages 단독 X** → 해당 시기 명시
- 캡션에 "0~3개월", "백일 아기", "신생아용" 직접 표현 있으면 그대로
- 어른·가족 단위(공기청정기, 식기세트)일 때만 all_ages

### 안전 마진 룰 (애매하면 더 넓게)
사용자가 검색·필터 시 카드가 누락되지 않게, 적용 가능한 시기는 모두 포함:
- **베개·매트·잠자리 용품**: `newborn, infant, toddler` (신생아부터 사용)
- **선크림·자외선차단**: `infant, toddler, elementary` (영아부터 외출)
- **젖병·분유**: `newborn, infant` (둘 다)
- **이유식·식판·식기**: `infant, toddler`
- **장난감·교구**: 캡션의 대상 연령 따름 (없으면 `infant, toddler`)
- **모델 모집 (걷기 전·이전)**: `newborn, infant`
- **아동복**: 대상 시기 명확하면 그것만, 모호하면 `newborn, infant, toddler`

원칙: **너무 좁게 잡아 누락하는 것보다, 1~2 시기 더 넓게 잡는 게 낫다.**
단 `all_ages` 는 진짜 가족 단위 (공기청정기·청소기) 만.

---

## type_tags (복수 가능)

- `regram`: 본인 피드에 리그램(재게시) 필수
- `experience`: 체험단 — 제품 받고 후기·SNS 게시 의무
- `kids_model`: 키즈모델·아동 모델
- `supporters`: 서포터즈 — 장기 SNS 활동 (주 N회) 약속
- `form`: 별도 폼 작성 필수 (구글폼·네이버폼·카카오톡 채널 신청서)
  - 댓글·DM 만으로 신청 가능하면 form 아님
  - 다른 태그와 자유 조합 가능 (예: experience + form)

---

## topic (필수, 둘 중 하나)

- `parenting`: 아이가 주체 (이유식·기저귀·완구·교구·키즈모델·아동 체험단)
- `living`: 살림 (가전·가구·식기·청소·침구 — 가족 단위)
- 애매하면 `parenting` (육아 사이트 디폴트)

---

## deadline 추출 (캡션 본문 적극 탐색)

자주 나오는 패턴:
- "~까지", "마감: X월 Y일", "X월 Y일(요일) 자정", "X/Y 23:59"
- "선착순 N명 (~ 마감)"
- "이번 주 일요일까지" → 게시일 기준 가장 가까운 일요일 23:59 KST
- "오늘부터 7일간", "1주일간" → 게시일 + 해당 기간

ISO 8601 with +09:00 형식. 없으면 `null` (시스템이 자동으로 게시일 + 7일로 처리).

## search_keywords (검색 동의어, 콤마 구분 1~3개)

### ⚠️ 핵심: 제목·본문에 이미 있는 단어 절대 X
**제목·본문에 있는 단어를 또 search_keywords 에 넣으면 의미 없음.** (이미 검색되니까)
search_keywords 의 목적은 사용자가 **다른 표현으로 검색했을 때도 카드가 잡히게** 하는 것.

### 좋은 예 (동의어·유사어·상위어)
| 본문 | search_keywords |
|---|---|
| "신생아 젖병 2종 증정" | "수유용품,분유병" |
| "허그곰 쿨링 베개" | "유아베개,쿨매트,잠자리" |
| "야외놀이 쿨링 선스프레이" | "선크림,자외선차단,UV차단" |
| "100일 빨대컵·빨대젖병" | "수유용품,컵" |
| "베이비수트 모델 모집" | "아기모델,키즈모델,베이비모델" |
| "젖병 스타터 크루" | "수유용품,분유병" |

### 나쁜 예 (본문 단어 중복)
| 본문 | search_keywords | 문제 |
|---|---|---|
| "여름 신상 사전 증정" | "여름신상,추첨증정" ❌ | 본문에 다 있는 단어 |
| "선스프레이 체험단" | "선스프레이,자외선차단" ⚠ | "선스프레이" 본문 중복 |
| "100일 빨대컵" | "빨대컵,빨대젖병" ⚠ | 둘 다 본문에 있음 |

### 원칙
1. 본문·제목 단어 검색해서 **확실히 다른 단어** 만 넣기
2. 동의어 안 떠오르면 `null` (억지로 본문 단어 넣지 말 것)
3. 1~3개 (너무 많으면 노이즈)

## confidence (0.0 ~ 1.0)

분류에 얼마나 자신 있는지. 사용자 검수 우선순위 결정용.

### 기본 점수 = 0.85 에서 시작 → 가감

**+0.05 ~ +0.10 (자신감 ↑)**
- 캡션에 제품명·이벤트 형식 명시적
- 마감일 정확히 표기 (예: "5/31 까지")
- 시기 단서 직접 표현 ("100일 아기", "0~3개월")
- 키즈모델·서포터즈처럼 형식 명확

**-0.05 ~ -0.15 (자신감 ↓)**
- 캡션이 200자 미만으로 짧음
- 마감일 추정 ("이번 주", "곧" 등 모호)
- 시기 단서 없어서 추정
- 캡션 잘림 (`✔️` 끝, `...` 끝)
- 모집 vs 단순 광고 헷갈림

### 범위 의미
- **0.90~1.00**: 거의 확실, 검수 X 발행 가능
- **0.75~0.89**: 일반적, 검수에서 한 번 확인
- **0.60~0.74**: 단서 부족, 검수 권장 (제목·시기 수정 가능성)
- **0.50~0.59**: 모호, 검수 강력 권장
- **0.50 미만**: **사용자에게 직접 확인 요청** (대화로 물어봄)

### 결과 일관성을 위해
같은 캡션을 다른 세션에서 분류해도 ±0.05 안에서 결과 나오게 위 기준 엄격히 따르기.

## 운영 노트 (너님이 매일 추가)

### 2026-05-28: 두 세션 결과 비교로 학습
첫 운영 라운드에서 두 다른 Claude 세션이 동일 JSON 분류했는데 결과가 갈렸어요. 원인 → 룰 강화:
- **title 에 브랜드명 X** (PostCard 가 brand_name 별도 표시 — 위 "제목" 섹션)
- **시기 분류 안전 마진** (베개=신생아부터, 선크림=영아부터 — 위 "stage_categories" 섹션)
- **search_keywords 본문 단어 중복 금지** (동의어만 — 위 search_keywords 섹션)
- **신뢰도 기준표 명문화** (0.85 기준 → +/- — 위 "confidence" 섹션)

### 자주 등장하는 브랜드 (정렬: 표 추가)
위 "자주 등장하는 브랜드" 표에 운영하며 발견한 브랜드 한 줄씩 추가.

### skip 패턴 (운영하며 추가)
- "협찬 받았어요" 단독 후기 → skip (모집 X)
- 매장 영업 시간·휴무 안내 → skip
- 특정 사용자 답글 형식 게시물 → skip (모집 흐름과 무관)

## 검증

results.json 만든 후:
1. items 수 = 입력 items 수 ?
2. queue_id 다 매칭됐나 ?
3. skip 외 모든 항목이 title 있나 ?
4. stage_categories 가 배열 (string 아님) ?
5. deadline 이 ISO 8601 +09:00 형식 ?

이상 OK 면 사용자에게 결과 요약 보고 후 import 진행 안내.
